# Dubai Real Estate Investment Tier Prediction

## Project Overview

This project applies an end-to-end machine learning workflow in Python to classify Dubai real estate transactions into **Premium High-Value Investments (`1`)** versus **Standard Value Transactions (`0`)**. The Streamlit web application loads the best-performing model pipeline and displays both the predicted investment tier and its probability score.

## Machine Learning Models

The project compares two supervised classification models:

- **Decision Tree Classifier** (`DecisionTreeClassifier`)
- **Bernoulli Naive Bayes** (`BernoulliNB`)

Both models are tuned using `RandomizedSearchCV` with 3-fold Stratified Cross-Validation optimizing the **F1 score**. The winning model pipeline is exported to `dubai_property_model.pkl` for deployment in Streamlit.

## Dataset & Licensing

The project uses a single 250,000-record sample extracted from the **Dubai Real Estate Sales Transactions** dataset (originating from official Dubai Land Department open data):

- `Training Dataset.csv` — 250,000 records used for data cleaning, EDA, and feature engineering. The pipeline internally splits this data 80/20 for model training (160,000 rows) and validation (40,000 rows).

**Target Variable (`Result`):**
- `0` = Standard Value Property (Below market median transaction value of 1.36M AED)
- `1` = Premium High-Value Property (At or above market median transaction value of 1.36M AED)
